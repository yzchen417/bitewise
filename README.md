# BiteWise · 知食

> AI 驱动的饮食记录与营养分析工具

![Preview](https://img.shields.io/badge/Platform-H5%20%7C%20PWA-brightgreen)
![AI](https://img.shields.io/badge/AI-Gemini%201.5%20Flash-blue)

## 功能特性

- 📸 **拍照识别** - Gemini 1.5 Flash AI 智能识别食物营养成分
- 📊 **热量看板** - 实时展示今日摄入与目标对比
- 📅 **历史统计** - Chart.js 可视化周/月趋势
- 🎨 **多主题** - 莫兰迪绿 / 极简白 / 深邃黑
- 💾 **本地存储** - 数据完全存储在本地，保护隐私
- 📱 **PWA 支持** - 可添加到手机桌面，离线使用

## 技术栈

- 纯原生 HTML/CSS/JavaScript（无框架依赖）
- Gemini 1.5 Flash API（Google AI）
- Chart.js 4.4.1（数据可视化）
- LocalStorage（数据持久化）
- PWA（渐进式 Web 应用）
